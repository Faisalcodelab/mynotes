📝 Keep Notes
A simple note-taking app to help you create, save, and download notes in a user-friendly interface.

🚀 Features
Create Notes: Type your notes in a text area and save them.
Save Notes: All entered notes are saved and displayed on the page.
Download Notes: Save all notes as a text file for later use or sharing.

🎮 How to Use
Enter your note: Type your text into the text area.
Save your note: Click the “Save Note” button to save your note, which will be listed below the text area.
Download your notes: Click the "Download Text" button to download all your notes as a .txt file.

🛠️ Technologies Used
HTML – Structure for the note-taking app interface.
CSS – Styling for layout, fonts, and overall look of the app.
JavaScript – Functions for saving notes, displaying them, and downloading them as a text file.

📌 Future Improvements
